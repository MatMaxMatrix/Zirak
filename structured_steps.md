### Structured Steps for Analyzing User Request:

1. **Objective Identification:**
   - **Objective:** Identify the main objective and requirements in the user's request.
   - **Instructions:** Analyze the user's request to extract the main objective and requirements.
   - **Technical Requirements:** Text parsing and analysis tools.

2. **Action Term Extraction:**
   - **Objective:** Identify and extract key action terms such as 'analyze,' 'break down,' and 'steps.'
   - **Instructions:** Analyze the extracted text to identify key action terms.
   - **Technical Requirements:** Natural language processing tools.

3. **Task Breakdown:**
   - **Objective:** Break down the user's request into individual steps for a comprehensive analysis.
   - **Instructions:** Separate tasks into structured steps for a detailed breakdown.
   - **Technical Requirements:** Text processing and structuring tools.
